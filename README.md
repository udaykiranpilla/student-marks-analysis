# 📊 Student Academic Performance Report – Sri Chaitanya Techno School

## 📌 Overview  
This project analyzes the academic performance of **36 students (18 boys, 18 girls)** over **six OT exams** in the subjects **Maths A, Maths B, Physics, and Chemistry**. The objective is to identify performance trends, uncover learning gaps, and support data-driven academic decisions. Data was processed using **Python (Pandas, NumPy)** and visualized using **Tableau**.

---

## 📂 Dataset  
- `SCS OT Exam Analysis 2025.csv` – Raw student marks data  
- `cleaned_data.csv` – Cleaned and structured dataset  
- **Fields:** Student ID, Name, Exam, Maths A, Maths B, Physics, Chemistry, Total Marks

---

## 🧮 Tools Used  
- **Google Colab (Python)** – Data cleaning and transformation using Pandas, NumPy  
- **Tableau** – Data visualization and dashboard development
