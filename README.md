# 📊 Student Academic Performance Report - Sri Chaitanya Techno School

## 📌 Overview
This project analyzes the academic performance of **36 students (18 boys and 18 girls)** over **six OT exams** in the subjects **Maths A, Maths B, Physics, and Chemistry**. The dataset contains student details, subject-wise marks, and total scores. The insights are visualized using **Tableau** to identify trends and patterns in student performance.

## 📂 Dataset
- **File:** `SCS OT Exam Analysis 2025.csv`
- **Cleaned Data CSV:** `cleaned_data.csv`
- **Contents:** Student ID, Name, Exam, Marks in Maths A, Maths B, Physics, Chemistry
